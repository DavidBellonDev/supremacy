# Projeto
Supremacy é um sistema básico de cadastro de clientes, produtos, pedidos de vendas e geração de relatórios. O objetivo é obter conhecimento para o desenvolvimento web com as tecnologia indicadas a seguir.

# Tecnologias
- PHP
- CodeIgniter 4
- JavaScript/JQuery
- Bootstrap 5
- DataTables
- Ajax
- SweetAlert
- CSS

# Instalação
Basta apenas baixar o projeto em sua máquina local e abrir em uma IDE como VisualStudio. O Banco de Dados configurado é para rodar localmente.
